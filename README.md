# Controle de Motor de passo com Joystick

## Descrição
A ideia do projeto é criar um controle de motor de passo com a utilização de um joystick. O exemplo pode ser usado de diversar formas, a ideia inicial era para um controle de casa inteligente e essa seria uma das funções. Porém como é apenas um projeto informal foi escolhido praticar de forma fragmentada
O projeto tem o intuito simples de praticar minha documentação de projetos eletrônicos e elaborar uma maneira fácil e otimizada de demonstrar meus projetos aqui no github.
Testar qual melhor formato e o que faz sentido ou não incluir e como se deve incluir !

## Funcionalidades
- Contorle no sentido horpario e anti horário de um motor de passo através do joystick.

## Hardware
| Componente | Quantidade |
|---|---:|
| ESP32-WROVER | 1 |
| Joystick | 1 |
| Motor de Passo  5v | 1 |
| ULN2003 Driver de Motor Passo | 1 |
| Protoboard | 1 |
| Jumpers | vários |
